# 底栏与习惯列表修正

日期：2026-10-05。

## 行为

- 底栏仅绘制一个 180ms 平移的高亮滑块，移除按钮自身的 RippleDrawable，
  避免点击涟漪和滑块同时出现。键盘焦点边框、selected 语义和禁用动画支持保留。
- 习惯行仅显示名称，不显示「待完成 / 已完成」副标题；勾选框保留 checked
  和状态无障碍描述。名称、勾选框、菜单在整行中垂直居中，触摸目标仍为 48dp。
- 查看创建日期之前的日期时不显示该习惯；创建当天开始显示。
  历史中已存在的其他习惯保留，归档历史继续遵守原有日期边界。
- 不改变 Room schema、备份格式或计时与 Tags 的规则。
