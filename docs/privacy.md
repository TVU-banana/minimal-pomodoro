# 隐私说明

Clock 不申请网络权限，不包含广告、分析、账号或远程崩溃上报。任务名称、类别、倒计时历史和背景图片仅保存在设备本地。

只有在用户主动选择“导出”时，Clock 才通过 Android 系统文件选择器写入 CSV 或 `.clockbackup`；只有在用户主动选择“导入”时才读取相应文件。用户应将包含个人活动记录的备份保存在可信位置，如使用 Git 保存个人备份，备份仓库应设为私有，并与本项目源码仓库分离。

“保存长期归档”会把同一开放备份写入用户选择的、应用沙盒之外的位置，因此卸载不会删除它。
应用无法改变 Android 系统卸载界面的行为；只有用户在 Clock 内确认“删除长期归档”或在文件管理器中明确删除文件时，该副本才会被删除。


## 公开源码与验收附件

本项目源码可以公开，但签名密钥、设备标识、开发机日志与个人数据不得进入 Git。
公开展示图片应来自专用模拟器和合成数据。历史真机验收附件保留于维护者本地，
不会作为公开示例分发；文字验收记录只代表当时注明的环境和范围。
