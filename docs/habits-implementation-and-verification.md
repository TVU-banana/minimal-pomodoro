# 每日习惯打卡：实现与验收

验证日期：2026-10-04。参考 [技术评估细则](../GPT-打卡功能拓展技术评估细则.md)。
底栏采用用户指定顺序：**计时 → 打卡 → 记录 → 设置**。

下面的原始验收证据与截图来自 2026-10-04；创建前可见性和状态副标题的后续调整
见 [2026-10-05 修正验证](habit-and-navigation-fixes-verification.md)。

## 已实现的规则

- 每日习惯拥有独立定义和本地日期记录，不关联 Tags、计时模板或 Session。
- 支持创建、改名、上下排序、归档、完成、撤销、历史补打、日期选择和回到今天。
- 名称按原文保存，不从「×2」等提示推断次数；首版使用每日二元完成状态。
- 未来日期禁止打卡；创建前的日期不显示该习惯，不计入完成总数。
- 归档立即隐藏今天的入口；之后仍可查看并编辑有效历史，包括归档当天。
- 撤销保留更新后的 false 记录，较旧备份不能重新恢复已撤销的完成状态。
- 日期键使用 LocalDate；跨时区不重写旧日期。前台、日期/时区变化及次日边界刷新 UI。
- Room 是事实来源，写入经 HabitRepository 单次事务执行；已接受的写入不随切页取消。
- 不增加网络权限、常驻服务、提醒或周期写库。

详细边界见 [ADR 0007](decisions/0007-independent-daily-habits.md)，
公开备份协议见 [data-format.md](data-format.md)。

## 界面与进度条

打卡页复用现有中性色、主题强调色、细分隔线和轮廓图标。
日期条在窄屏横向滚动，名称最多两行，完整名称保留在编辑与无障碍描述中。
圆形打卡和菜单目标为 48dp；状态由勾选图标和原生 checked 语义表达。
2026-10-05 调整：移除名称下的状态文字，行操作随名称垂直居中；隐藏创建前的习惯。
短横屏加大字体时使用日期选择器与范围箭头，保留完整的列表操作区域。

计时页左上角现有进度条居中显示 12sp 常规百分比：无目标为 0%，最高为 100%。
未填充区域使用主题次级文字色，填充区域使用 on-primary 色；颜色沿实际圆角填充边缘切换。
百分比格式化与几何计算不进入 onDraw 热路径，原有点击明细和无障碍描述保留。
该百分比仍属于专注目标，与习惯打卡保持独立。

## 验证证据

| 范围 | 结果与证据 |
|---|---|
| 完整单元测试 | 99 项，0 失败/错误；含日历、时区、夏令时、并发、撤销和备份冲突规则。 |
| Android Lint | 0 错误、97 条警告；警告仍保留，不能视为 warning-free。 |
| 构建 | Debug、R8 Preview、Release 均 BUILD SUCCESSFUL。 |
| 真实 Room 测试 | 10 项通过：3 项迁移/约束测试，7 项磁盘持久化与备份服务测试。 |
| 7→8 迁移 | 使用导出的 schema 7 建立旧库，真实 Room 打开并验证 schema 8；旧业务数据保留。额外旧列的负向测试确实拒绝不匹配 schema。 |
| 模拟器旧库升级 | 实际 schema 3→8 升级后，原有 2 个 Tags、13 个模板、7 个 Session、8 个 segment 的所有原始列值不变。 |
| 打卡隔离性 | 创建、打卡、撤销、改名、排序、归档后，全部非习惯表的行值 SHA-256 与升级后基线一致。 |
| 备份服务 | v3 实际文件导出/读回/恢复至另一文件数据库；v1/v2 导入保留现有习惯；旧完成不覆盖新撤销。 |
| 原子拒绝 | 校验和有效但存在无效习惯外键的归档被拒绝，Room 无部分写入。 |
| 运行交互 | 创建、改名、排序、归档、完成/撤销、重启持久化、不适用日期、禁止未来日期及四项导航通过。 |
| 计时回归 | 开始、暂停、切换打卡页、返回相同剩余时间、结束和记录页查看通过。 |
| 真实渲染 | Android 17 / API 37 模拟器：正常手机、360dp 窄屏、200% 字体、横屏和平板尺寸，均检查深浅主题；禁用动画时也完成打卡交互。 |
| 百分比 | 0%、50%、100% 深浅主题及 200% 字体截图；50% 实际边缘跨越文字时保持可读，点击仍打开今日明细。 |

迁移、持久化和备份测试位于 `app/src/androidTest/`；单元测试位于 `app/src/test/`。
百分比 50%/100% 截图使用临时模拟器数据样本；检查结束后已还原，并核对所有表值一致。
未把原始数据库作为交付或备份协议。没有进行物理设备验收或实际 TalkBack 朗读，
无障碍验证限于 Android UI hierarchy 中的名称、可用性及 checked 状态。
