# UI/UX 优化验收

2026-10-03。基于本次开始时的工作区增量修改，保留已有未提交功能开发。

## 设计结果

本轮改为紧凑列表，删除页面“专注”标题；实际时间块名称和用户标签继续保留。
顶栏保留今日电池进度、深浅滑动胶囊、加号，统一中性色、细线和垂直中心；电池与
主题轨道的视觉高度均为 28dp。顶栏与列表之间增加与底栏一致的 1dp 分隔线。

时间块从 94dp 缩为 64dp，去掉白色卡片、围框与卡片间空隙，只保留细分隔线。
名称和淡染标签同排，第二行显示 `60min · 15min`，去掉“预热”。标签使用 11sp
次要文字和 20dp 视觉胶囊；开始图标放大为无底的轮廓三角。底栏从 76dp 缩为
49dp，图标与文字横排，以短下划线标示选中项。所有操作继续保留 48dp 点击高度。
同一正常字号、360dp 屏幕可完整显示 7 个时间块，上一版只能完整显示 3 个。

LCD 仅绘制实际数字，采用主文字色；删除底色面板和淡显的未亮数字。字形与计时语义
保留，报表和设置保留原有功能与入口。

设计令牌和参考来源见 [设计系统](../design-system/clock/MASTER.md)。
实际 Android 截图见 界面画廊（本地验收附件，不公开分发），图片未作视觉修饰。

## 范围与限制

标签使用已有 `colorArgb` 淡染页面背景：浅色混入 6%，深色混入 10%；文字采用
次要中性色，不对整个标签降低透明度，保持可读性。同名标签仍由胶囊形状区分。
点按标签可使用现有编辑器选择预设颜色，
或输入 `#RRGGBB`；颜色保存到已有 Room 字段，不增加迁移或改变标签统计。

今日总进度使用现有明细的完成时长规则，对关联有效标签的计时记录去重计数，目标
为有效标签的每日目标总和。无目标时显示累计分钟数，电池不显示比例填充。数据只
随 Room 变更或页面恢复读取，不随计时器每秒刷新查询或写入数据库。

LCD 使用 [DSEG 官方字体](https://github.com/keshikan/DSEG) 的 DSEG7 Classic Regular
v0.46（约 23KB），采用 SIL Open Font License 1.1。本地随包提供字体及完整授权文件，
无需联网；比例、斜切电极和间隙均采用原字形。普通界面文字仍使用系统字体。

本次增量集中在 UI、资源和设计文档；通知管理器仅替换小图标资源。没有修改计时
reducer、Room、Coordinator、闹钟调度和备份格式，没有增加依赖或网络权限。

运行验证使用 Android API 37 模拟器，保留应用数据，操作产生少量测试计时记录。
本轮按用户要求仅调试正常字号；先前报表和导出流程的验收记录不代表本轮重新操作。
多标签布局通过临时勾选第二标签检查；随后重新打开编辑器核对原单标签已恢复。
这不是实体手机或后台闹钟可靠性的验收；未重新测试杀进程、重启恢复、真实设备
锁屏、TalkBack 全流程和文件备份往返。已有功能测试仍通过。
