# 底栏高亮滑块与打卡入口调整

验证日期：2026-10-05。

底栏顺序保持「计时、打卡、记录、设置」。选中项使用共享圆角高亮背景，
切页时以 180ms 平移；系统禁用动画时立即定位。点击范围保持至少 48dp，
无障碍节点保留按钮角色、名称和 selected 状态。

打卡页从日期开始，移除顶部「每日打卡」和加号；唯一的新建入口位于右下角。
按钮为 56dp、中性实心背景、细线加号，随深浅主题调整背景和图标颜色。
列表底部留出 96dp 滚动空间，让最后一条习惯的操作可以避开按钮。
本次改动未修改习惯、Tags、计时、记录及备份的持久化规则。
